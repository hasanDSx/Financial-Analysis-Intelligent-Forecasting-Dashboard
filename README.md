________________________________________
This project focused on building a dashboard that feels fast, clean, and intuitive, while still providing strong analytical depth.
A lot of effort went into structuring Selections and Bookmarks to control navigation, filters, and visual states in a smooth and organized way.

## Global KPIs (Visible on Every Page)
* Units Sold

* Gross Sales

* Discounts

* Net Sales

* Cost of Goods (COGS)

* Profit

*These KPIs remain fixed across all pages to maintain full business context.*
________________________________________
## Dashboard Structure

### Home Page

An introduction page with clear navigation and “Learn More” buttons under each main measure (Units Sold, Net Sales, COGS, Profit) to guide users into deeper analysis.
________________________________________
## Core Analysis Pages (Period | Segment | Country | Product)

### Each page includes:

* Units Sold, Net Sales, Profit, and COGS by dimension

* A dynamic summary table with all key measures and Profit Margin

* Tooltips on every chart showing manager-level performance insights
________________________________________
## Export Page

A single detailed view with all KPI cards and one large table covering all dates, dimensions, and measures.

### Smart Filters & Navigation

* Manager filter with dynamic photo and profit margin

* Dedicated reset button for manager selection

* Global reset button for the entire dashboard

Behind the scenes, the dashboard relies heavily on advanced Selections and Bookmarks organization to manage states, navigation, and visual behavior — making the entire experience fully dynamic and seamless.
